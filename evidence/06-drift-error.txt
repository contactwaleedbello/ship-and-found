Defect: Intentional Database Drift (Client ORM Types Updated Ahead of Physical Storage)

--- 1. Triggering Drift: Schema Edit & Client Generation Without Migration ---
Added `creditScore Int @default(700)` to `prisma/schema.prisma`.
Executed:
$ npx prisma generate
✔ Generated Prisma Client (v5.22.0) to ./node_modules/@prisma/client in 116ms

Note: No migration command (`npx prisma migrate dev` or `prisma db push`) was executed.

--- 2. Runtime Application Execution & Captured Client Error ---
$ node -e "
const { PrismaClient } = require('@prisma/client');
const prisma = new PrismaClient();
prisma.user.findFirst({ select: { id: true, creditScore: true } })
  .catch(err => {
    console.error('=== DRIFT RUNTIME CLIENT ERROR CAPTURED ===');
    console.error('Code:', err.code);
    console.error('Message:', err.message);
  });
"

Output Captured:

Code: P2022
Message: 
Invalid `prisma.user.findFirst()` invocation:


The column `main.User.creditScore` does not exist in the current database.

--- 3. What Two Things Went Out of Step (One Paragraph Explanation) ---
The two things that fell out of step were: (1) the TypeScript compile-time model definitions compiled into the Prisma Client query engine at `node_modules/@prisma/client`, and (2) the physical table structure of the relational database catalog (`dev.db`). Running `prisma generate` creates a dangerous illusion of readiness: TypeScript static type checking passes because the compiled types include the `creditScore` field, but the physical relational storage engine never received the `ALTER TABLE` DDL instruction. The moment a query requests the field, the database engine returns error `P2022`, terminating the request.

--- 4. Drift Remediation & Resolution Proof ---
Executed migration to synchronize the physical storage with the ORM schema:
$ npx prisma migrate dev --name add_credit_score
Applying migration `20261031232503_add_credit_score`
Your database is now in sync with your schema.

Re-executed query:
$ node -e "
const { PrismaClient } = require('@prisma/client');
const prisma = new PrismaClient();
prisma.user.findFirst({ select: { id: true, creditScore: true } })
  .then(res => console.log('Resolved Query Result:', res));
"
