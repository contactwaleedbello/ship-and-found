#response
What Could Not Be Done With Tokens Alone
Page Container Max-Width:

The token system defines --spacing-layout-margin and --spacing-layout-fixed-pane-width, but does not provide a top-level page max-width token (e.g., 960px or 1200px) to constrain wide desktop layouts. Rather than inventing raw pixel widths, the layout uses width: 100%, margin: 0 auto, and responsive CSS Grid columns (@media (min-width: 840px)).
Image Container Dimensions / Aspect Ratio:

The design system provides component heights for app bars (--spacing-component-app-bar-height) and touch targets (--spacing-component-target-min), but no dimensions or aspect-ratio tokens for media cards. The product box uses unitless aspect-ratio: 1 / 1; and width: 100%; with tokenized border radius (--radius-image), borders (--border-width-outline), and shadows (--shadow-soft).
Chassis Color Swatches:

The design system provides semantic role variables (--color-primary, --color-surface, etc.), but no product hardware color tokens for "Blue Black", "Light Blue", or "Yellow". In strict adherence to the rule against raw hex/rgb/hsl values, the color selection options are styled using --color-surface-container chips.
Struck-Through / Comparison Price Text Role:

There is no specialized typography or color role for discounted/struck-through reference pricing; this was styled using --color-on-surface-variant with .type-title-medium.
